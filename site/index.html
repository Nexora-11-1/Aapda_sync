Nexora · multi-hazard civil protection

Risk, exposure and evacuation, resolved into one decision.

AapdaSync ingests Indian authority data, scores hazard risk on an H3 grid, estimates who is physically exposed, ranks areas for relocation with a transparent explanation, models real shelter capacity, and routes evacuation over a road network whose state changes in real time.

The distinction the whole design rests on

Coverage and registers come from different places, so they are never mixed.

Most dashboards blur a computed figure into a reported one and present the result as a single number. This one cannot: derived and declared are different objects, drawn differently, and a state without a feed is drawn as no data rather than as a safe green cell.

Derived · national

Modelled risk is computed for the whole country

IMD/Open-Meteo, GloFAS, USGS/GDACS, INCOIS and FIRMS cover all of India, so a risk surface can be computed for any state honestly.

  • Risk scored on an H3 grid, every tick, for all 36 states
  • Exposure as a spatial overlay — not p × population
  • Every response carries its attribution and its data freshness
Declared · local

Registers belong to a State Disaster Management Authority

Shelter capacity and road state are local records. Chamoli District, Uttarakhand is the integrated MVP. Every other state shows a provisional register, and the interface says so on the screen, every time.

  • A declared figure is shown as reported, never totalled with a computed one
  • No feed means capacity is marked not available — not zero, not estimated
  • Connecting one more district is a concrete, costed step
From a gauge reading to an evacuation order

One chain, and every link says what it used.

Raw inputs go in — ground motion, flood depth, slope susceptibility, plume fraction, floor area, litres per day, latrine counts, road throughput. Every number on every screen is derived from them. Change an input and the whole chain moves.

A stalled pipeline says so. orchestrator.tick_watchdog distinguishes never ran from stalled, lagging and healthy, exports PIPELINE_LAG, and publishes pipeline_health to every open dashboard. /readyz fails once the pipeline is more than six risk intervals behind, so a load balancer pulls the instance rather than serving figures that have quietly stopped moving.

What real time means here

The platform cannot be faster than the authorities it reads. What it guarantees is zero added latency.

IMD publishes on its own cadence; CWC's gauges report when they report. The moment a fact arrives it is processed and on every open dashboard. Three paths, in order of speed.

PathLatencyUsed by
Push ingress ~1 s to the dashboard Authorities and SDMA integrations that can push. POST /api/ingest/event, HMAC-signed and replay-protected.
Write-through ~1 s Operator writes — a shelter fills, a road is cut, a report is verified. Each triggers an immediate district recompute.
Polling source-dependent The floor, for sources with no push. Per-source cadence, as tight as each one's rate limit allows.

Nothing on screen is a baked-in timestamp

Every displayed time is derived at render time from the wall clock in Asia/Kolkata, so an alert seeded "37 minutes ago" reads as 37 minutes ago whenever the page is opened. The loop measures elapsed wall-clock time rather than counting ticks: if a tab is throttled or the machine sleeps, the missed intervals are replayed on return.

The clock is an input, not a decoration

India's hazards are strongly seasonal and partly diurnal, and the opening state is derived from what time it actually is — flood and landslide in the southwest monsoon, cyclone in the post-monsoon Bay season, heat and fire before the monsoon breaks. Open it in November and Odisha leads on cyclone; open it in February and the country is quiet.

The number nobody else computes

Physical capacity is not safe operational capacity.

A hall rated for 5,000 with 4,200 already inside, water for 400 people and one nurse does not have 800 usable places. It has whatever the binding constraint says it has — and knowing which constraint binds is the operationally useful part, because it tells you whether to send a tanker or open another hall.

The engine recomputes on every shelter status update and on every risk tick, because a shelter that has just come inside a hazard footprint has an effective capacity of zero, regardless of how much floor it has.

Chosen for a reason, and the reason is testable

Four algorithms, four bounds — each asserted by a test rather than by prose.

Every bound below has a case in backend/tests/test_daa.py that measures it.

WhereAlgorithmBoundWhy this one
spatial/quadtree.py Recursive quadrant subdivision Θ(n) worst case Risk is spatially autocorrelated. Proving a quadrant uniform is cheap; the budget goes to quadrants that disagree with themselves. Measured prune rate ≈ 0.72 on a live monsoon tick.
priority/mergesort.py Merge sort Θ(n log n), all cases Stability under a documented tie-break, so the evacuation queue does not reshuffle between ticks; an auditable comparison trace; no pathological case inside a 15-minute deadline.
spatial/nearest.py 2-d k-d tree build Θ(n log n) · query Θ(log n) Shelter candidate generation in microseconds with no database round trip. Projected to metres — comparing degrees is subtly wrong north–south.
routing/graph.py Dijkstra one-to-many · A* point-to-point Θ((V+E) log V) One Dijkstra per zone costs less than A* per shelter. The A* heuristic is great-circle ÷ max speed: admissible and consistent, so the result is provably optimal.
Enforced in code and covered by tests — not stated as intent

The rules that are not style.

01

A model prediction is never presented as a warning

Every risk response carries its attribution. Official alerts live on a separate endpoint with the issuing authority intact.

02

Stale is never presented as live

Sources past their staleness window are marked. A stopped pipeline fails /readyz rather than serving its last figures as current.

03

No data is not zero risk

A cell with no model output renders hatched, as no data — never as a safe green cell.

04

Exposure is a spatial overlay

8,200 people in a cell 12 m above the drainage line are not 5,250 people at risk. Not p × population.

05

Priority is reconstructible

Displayed contributions sum to the score exactly. PriorityEngine.verify raises if they ever diverge.

06

No invented endpoints

A credentialed source with no credential reports NOT_CONFIGURED and calls nothing. One failed source never takes down the platform.

07

A repaint never takes the reader's place

Nothing rebuilds the screen on a timer while somebody is scrolling, dragging or typing. Scroll position and focus come back afterwards.

08

An interaction costs what it is worth

A two-pixel twitch does not pan. A pan that moved does not also open what it ended on. One finger on a phone always scrolls.

09

A photograph without a credit is not displayed

Not by the build, not by the browser drop-in path. An unchecked credit says so on the image, not only in the build log.

Two ways to run it

The full stack, or one file on a USB stick.

Full stack

API · worker · PostGIS · Redis · frontend

Starts with no credentials. Every credentialed source reports NOT_CONFIGURED, which is a supported running state — the platform runs, marks those sources in the UI, and reduces the confidence of predictions that needed them.

# set POSTGRES_PASSWORD and AAPDA_JWT_SECRET
cp .env.example .env
docker compose up -d --build

# build the grid and load infrastructure
docker compose exec worker python scripts/build_grid.py
docker compose exec worker python scripts/load_osm.py

# what can this host actually reach?
cd backend && python scripts/check_sources.py
Offline

One self-contained HTML file

No server, no build step, no network beyond two web fonts — and it falls back to system fonts cleanly without them. It is what you email, put on a USB stick, or run in a district control room with no uplink.

# rebuild the single file
cd frontend/standalone
node build.js
#  → ../dist/aapdasync.html

# or just open the published one
open frontend/dist/aapdasync.html
